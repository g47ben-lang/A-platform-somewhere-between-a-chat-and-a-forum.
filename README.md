# מערכת ועד קמ"ד ישיבת חברון

אתר קהילה סגור לכמה מאות חברים. הוא בנוי בשלוש שכבות:

**ערוצים** ← **נושאים** (כותרת והודעת פתיחה, כמו בפורום) ← **שיחה חיה** בתוך כל נושא (כמו בצ'אט).

## מה יש באתר

**צ'אט ראשי:** מסך הבית הוא שיחה חיה של כל הקהילה, עם תמונת הרקע בראש המסך.

**בועות הודעה בסגנון Google Chat:**
- ההודעות שלך מופיעות בצד השני בכחול, ושל האחרים באפור עם שם ותמונה.
- מעבר עם העכבר על הודעה (או הקשה בטלפון) פותח:
  - 3 תגובות אימוג'י מהירות, ובוחר אימוג'י מלא עם חיפוש בעברית;
  - ציטוט בתשובה;
  - תפריט ⋮: העברת ההודעה, סימון כלא נקראה, סימון בכוכב, הצמדה ללוח החדר, העתקת קישור להודעה, העתקת הטקסט, עריכה ומחיקה.
- ההודעות המוצמדות מרוכזות ב"לוח" של כל חדר, וההודעות שסימנת בכוכב בעמוד "מסומנות בכוכב".

**אימוג'ים:** מאגר גדול שנבחר לבחורי ישיבה: פרצופים, ידיים, לימוד וישיבה, יהדות וחגים, אוכל כשר, טבע ועוד. אין בו אימוג'ים לא מתאימים.

**תמונות וסרטונים:**
- אפשר לצרף מהמחשב או מהטלפון, או להדביק תמונה.
- תמונות מוקטנות אוטומטית. סרטונים מוגבלים ל-20MB ולדקה וחצי.
- הקבצים פרטיים וגלויים רק לחברים מאושרים.

**תמונת פרופיל:** מעלים מקובץ בעמוד ההגדרות.

**חדרי צ'אט, צ'אט אישי ותיוגים:**
- חדרים לנושאים מסוימים.
- שיחות אישיות, גם בעילום שם אם המנהל מתיר.
- תיוג עם `@`, חיווי "מקליד…", וקו "הודעות חדשות".

**כרטיס חבר:** לחיצה על שם או תמונה פותחת כרטיס עם מוניטין ואפשרויות לשלוח הודעה.

**אנונימיות בשליטת המנהל:**
- המנהל קובע מי יכול לשלוח בעילום שם ולמי אפשר לשלוח כך.
- גם תגובות אימוג'י בשיחה אנונימית לא חושפות את השולח.

**לייק ומוניטין:**
- לכל הודעה בחדרים יש כפתור לייק (אגודל), נפרד מתגובות האימוג'י.
- כל לייק שמתקבל מחבר אחר שווה 5 נקודות מוניטין לכותב, וכל הודעה שווה נקודה אחת.
- תגובות אימוג'י ותוכן אנונימי לא נספרים.
- אי אפשר לעשות לייק להודעה של עצמך.

**הצטרפות:** מנהל יכול להדביק את רשימת השמות של הישיבה ורשימת מיילים (ניהול ← אישור מראש). מי שנרשם עם שם מהרשימה (שם משפחה ופרטי, בכל סדר) או עם מייל מאושר נכנס מיד; על הצטרפות לפי שם המנהל מקבל התראה לבדיקה. אף אחד לא מקבל מייל או הודעה. בכניסה הראשונה כל חבר מאשר פעם אחת את תקנון התוכן (נטפרי).

**ניהול:** אישור וחסימת חברים, מינוי מנחים, ניהול חדרים והרשאות אנונימיות.

**התראות:** התראות בדפדפן על הודעות אישיות ועל תיוגים.

**שפה:** האתר כתוב כולו בלשון זכר.

## שימוש באחסון
בגרסה החינמית של Supabase יש 1GB אחסון ו-5GB תעבורה בחודש. תמונות מוקטנות אוטומטית, כך שהן תופסות מעט מקום. אם יעלו הרבה סרטונים, כדאי לעקוב בלוח הבקרה של Supabase אחרי הנתונים בעמוד **Storage** ובעמוד **Usage**.

## הקמה: פעם אחת, בערך 15 דקות

### 1. יצירת פרויקט ב-Supabase
1. נכנסים ל-https://supabase.com, נרשמים ולוחצים **New project**.
2. בוחרים אזור **Frankfurt (eu-central-1)**, הקרוב ביותר לישראל. שומרים את סיסמת מסד הנתונים במקום בטוח.

### 2. הקמת מסד הנתונים
1. בתפריט הצד: **SQL Editor** ← **New query**.
2. מדביקים את **כל** התוכן של הקובץ [`supabase/schema.sql`](supabase/schema.sql) ולוחצים **Run**.

### 3. הגדרות התחברות
ב-**Authentication**:
- **Sign In / Providers ← Email:** מומלץ לכבות את **Confirm email**. שירות המייל המובנה של Supabase מוגבל לכמה מיילים בשעה, וכשכמה עשרות אנשים נרשמים בבת אחת זה נתקע. גם בלי אימות מייל, אף אחד לא נכנס בלי אישור מנהל.
  - אם רוצים אימות מייל ואיפוס סיסמה במייל, צריך לחבר שירות SMTP. [Resend](https://resend.com) חינמי עד 3,000 מיילים בחודש. מגדירים אותו ב-**Authentication ← Emails ← SMTP Settings**.
- **URL Configuration:** ב-**Site URL** שמים את כתובת האתר (שלב 5). את אותה כתובת מוסיפים גם ל-**Redirect URLs**.

### 4. חיבור האתר ל-Supabase
כתובת הפרויקט והמפתח הציבורי (`sb_publishable_...`) שמורים בקובץ [`.env.production`](.env.production). המפתח הזה נועד להיות גלוי, וההגנה על הנתונים נעשית במסד הנתונים.

> ⚠️ את מפתח ה-**Secret** (`sb_secret_...`) לא מכניסים לריפו ולא לאתר, לעולם. הוא עוקף את כל ההרשאות.

כדי לשנות את שם הקהילה שמוצג באתר: ב-GitHub נכנסים ל-**Settings ← Secrets and variables ← Actions ← Variables** ויוצרים משתנה בשם `VITE_SITE_NAME`.

### 5. העלאת האתר לאוויר
1. ב-GitHub: **Settings ← General ← Default branch**. מגדירים את `main` כענף ברירת המחדל.
2. ב-GitHub: **Settings ← Pages ← Source: GitHub Actions**.
3. כל עדכון שנכנס לענף `main` מעלה את האתר אוטומטית. אפשר גם להפעיל ידנית: **Actions ← Deploy to GitHub Pages ← Run workflow**.
4. כתובת האתר: https://g47ben-lang.github.io/A-platform-somewhere-between-a-chat-and-a-forum./

### 6. כניסה ראשונה
נכנסים לאתר ונרשמים. **המשתמש הראשון הופך למנהל.** אחר כך שולחים את הקישור לחברי הקהילה, ומאשרים אותם בדף **⚙️ ניהול**. יש שם גם כפתור "אישור כולם", ואפשר גם להדביק מראש רשימת מיילים בלשונית **אישור מראש**.

## התראות במייל, אימות מייל ושחזור סיסמה (Gmail)

השירות המובנה של Supabase שולח מיילים רק לצוות הפרויקט, ולכן מחברים Gmail. אפשר לשלוח עד כ-500 מיילים ביום. **את סיסמת האפליקציה מכניסים רק ב-Supabase, ואף פעם לא בקוד או בצ'אט.**

1. **סיסמת אפליקציה ב-Gmail:** בחשבון Google שממנו ישלחו המיילים מפעילים "אימות דו-שלבי". אחר כך נכנסים ל-https://myaccount.google.com/apppasswords ויוצרים סיסמה בשם "chat". מקבלים 16 תווים.
2. **מיילי ההרשמה והשחזור:** ב-Supabase ← Authentication ← Emails ← **SMTP Settings** מדליקים את Enable Custom SMTP וממלאים:
   - Host: `smtp.gmail.com`
   - Port: `465`
   - Username: כתובת ה-Gmail
   - Password: סיסמת האפליקציה
   - Sender email: אותה כתובת
   - Sender name: `מערכת ועד קמ"ד ישיבת חברון`

   אחרי השמירה, "שכחת סיסמה" עובד.
3. **הגבלת קצב:** ב-Authentication ← Rate Limits מעלים את "emails per hour" ל-100.
4. **כתובת האתר:** ב-Authentication ← URL Configuration, ב-Site URL, שמים את כתובת האתר ב-GitHub Pages כדי שקישורי השחזור יחזרו לאתר.
5. **אימות מייל חובה בהרשמה:** ב-Authentication ← Sign In / Providers ← Email מדליקים את **Confirm email**. החשבון `shmuelshmuel@gmail.com` מאומת אוטומטית ולא צריך אימות.
6. **הפונקציה שמכינה ושולחת את המיילים:**
   - ב-Edge Functions ← Deploy a new function ← Via Editor, נותנים שם `send-emails`, מדביקים את כל התוכן של `supabase/functions/send-emails/index.ts` ולוחצים Deploy.
   - בהגדרות הפונקציה **מכבים את Verify JWT** (Enforce JWT Verification).
7. **סודות:** ב-Edge Functions ← Secrets מוסיפים `GMAIL_USER`, שהוא כתובת ה-Gmail, ו-`GMAIL_APP_PASSWORD`, שהוא סיסמת האפליקציה.
8. **הפעלה כל 5 דקות:** מריצים ב-SQL Editor את `supabase/email-setup.sql`. אותה הרצה מפרסמת גם את ברכות יום ההולדת כל בוקר.

**בדיקה:** פותחים בדפדפן את `https://aircrgkljjnomoemnetq.supabase.co/functions/v1/send-emails`, ואמורה להופיע תשובה קצרה עם `sent`. כל חבר בוחר בהגדרות ← "התראות במייל" על מה לקבל מייל ומתי.

### נייעסניק, בוט הנייעס (AI, חינם דרך Google AI Studio)
1. **פונקציה:** ב-Edge Functions ← Deploy a new function ← Via Editor, נותנים שם `bot`, מדביקים את כל התוכן של `supabase/functions/bot/index.ts` ולוחצים Deploy. **משאירים את Verify JWT דלוק** (רק חברים מחוברים יכולים לפנות לבוט).
2. **מפתחות:** נכנסים ל-aistudio.google.com/apikey ← Create API key. מתחברים לאתר כמנהל-על ← ניהול הקהילה ← "נייעסניק (AI)" ← מדביקים את המפתח. אפשר להוסיף כמה מפתחות, ולכל אחד מגבלה ליום ולדקה. הבוט בוחר את הכי פחות מנוצל, ומפתח שקיבל עומס נח דקה.
3. **בדיקה:** בכפתור "נייעסניק" בפינה הימנית התחתונה ← כותבים "מה הנייעס?".
4. **מכסה:** כל חבר מקבל 10 הודעות ביום על המפתחות של האתר (`bot_free_daily()` ב-schema.sql). אחרי זה נייעסניק מראה לו מדריך להוצאת מפתח חינמי משלו, שנשמר מוסתר ומשמש רק אותו.
