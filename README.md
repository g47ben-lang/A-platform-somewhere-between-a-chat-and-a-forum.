# מערכת ועד קמ"ד ישיבת חברון

אתר קהילה סגור לכמה מאות חברים. הוא בנוי בשלוש שכבות:

**ערוצים** ← **נושאים** (כותרת והודעת פתיחה, כמו בפורום) ← **שיחה חיה** בתוך כל נושא (כמו בצ'אט).

## מה יש באתר

**צ'אט ראשי:** מסך הבית הוא שיחה חיה של כל הקהילה, עם תמונת הרקע בראש המסך.

**בועות הודעה בסגנון Google Chat:**
- ההודעות שלך מופיעות בצד השני בכחול, ושל האחרים באפור עם שם ותמונה.
- מעבר עם העכבר על הודעה (או הקשה בטלפון) פותח:
  - 3 תגובות אימוג'י מהירות, ובוחר אימוג'י מלא עם חיפוש בעברית;
  - ציטוט בתשובה;
  - תפריט ⋮: העברת ההודעה, סימון כלא נקראה, סימון בכוכב, הצמדה ללוח החדר, העתקת קישור להודעה, העתקת הטקסט, עריכה ומחיקה.
- ההודעות המוצמדות מרוכזות ב"לוח" של כל חדר, וההודעות שסימנת בכוכב בעמוד "מסומנות בכוכב".

**אימוג'ים:** מאגר גדול שנבחר לבחורי ישיבה: פרצופים, ידיים, לימוד וישיבה, יהדות וחגים, אוכל כשר, טבע ועוד. אין בו אימוג'ים לא מתאימים.

**תמונות וסרטונים:**
- אפשר לצרף מהמחשב או מהטלפון, או להדביק תמונה.
- תמונות מוקטנות אוטומטית. סרטונים מוגבלים ל-20MB ולדקה וחצי.
- הקבצים פרטיים וגלויים רק לחברים מאושרים.

**תמונת פרופיל:** מעלים מקובץ בעמוד ההגדרות.

**חדרי צ'אט, צ'אט אישי ותיוגים:**
- חדרים לנושאים מסוימים.
- שיחות אישיות, גם בעילום שם אם המנהל מתיר.
- תיוג עם `@`, חיווי "מקליד…", וקו "הודעות חדשות".

**כרטיס חבר:** לחיצה על שם או תמונה פותחת כרטיס עם מוניטין ואפשרויות לשלוח הודעה.

**אנונימיות בשליטת המנהל:**
- המנהל קובע מי יכול לשלוח בעילום שם ולמי אפשר לשלוח כך.
- גם תגובות אימוג'י בשיחה אנונימית לא חושפות את השולח.

**מוניטין:** 5 נקודות על כל חבר שהגיב להודעה שלך, ונקודה אחת על כל הודעה. תוכן אנונימי לא נספר.

**ניהול:** אישור וחסימת חברים, מינוי מנחים, ניהול חדרים והרשאות אנונימיות.

**התראות:** התראות בדפדפן על הודעות אישיות ועל תיוגים.

**שפה:** האתר כתוב כולו בלשון זכר.

## שימוש באחסון
בגרסה החינמית של Supabase יש 1GB אחסון ו-5GB תעבורה בחודש. תמונות מוקטנות אוטומטית, כך שהן תופסות מעט מקום. אם יעלו הרבה סרטונים, כדאי לעקוב בלוח הבקרה של Supabase אחרי הנתונים בעמוד **Storage** ובעמוד **Usage**.

## הקמה: פעם אחת, בערך 15 דקות

### 1. יצירת פרויקט ב-Supabase
1. נכנסים ל-https://supabase.com, נרשמים ולוחצים **New project**.
2. בוחרים אזור **Frankfurt (eu-central-1)**, הקרוב ביותר לישראל. שומרים את סיסמת מסד הנתונים במקום בטוח.

### 2. הקמת מסד הנתונים
1. בתפריט הצד: **SQL Editor** ← **New query**.
2. מדביקים את **כל** התוכן של הקובץ [`supabase/schema.sql`](supabase/schema.sql) ולוחצים **Run**.

### 3. הגדרות התחברות
ב-**Authentication**:
- **Sign In / Providers ← Email:** מומלץ לכבות את **Confirm email**. שירות המייל המובנה של Supabase מוגבל לכמה מיילים בשעה, וכשכמה עשרות אנשים נרשמים בבת אחת זה נתקע. גם בלי אימות מייל, אף אחד לא נכנס בלי אישור מנהל.
  - אם רוצים אימות מייל ואיפוס סיסמה במייל, צריך לחבר שירות SMTP. [Resend](https://resend.com) חינמי עד 3,000 מיילים בחודש. מגדירים אותו ב-**Authentication ← Emails ← SMTP Settings**.
- **URL Configuration:** ב-**Site URL** שמים את כתובת האתר (שלב 5). את אותה כתובת מוסיפים גם ל-**Redirect URLs**.

### 4. חיבור האתר ל-Supabase
כתובת הפרויקט והמפתח הציבורי (`sb_publishable_...`) שמורים בקובץ [`.env.production`](.env.production). המפתח הזה נועד להיות גלוי, וההגנה על הנתונים נעשית במסד הנתונים.

> ⚠️ את מפתח ה-**Secret** (`sb_secret_...`) לא מכניסים לריפו ולא לאתר, לעולם. הוא עוקף את כל ההרשאות.

כדי לשנות את שם הקהילה שמוצג באתר: ב-GitHub נכנסים ל-**Settings ← Secrets and variables ← Actions ← Variables** ויוצרים משתנה בשם `VITE_SITE_NAME`.

### 5. העלאת האתר לאוויר
1. ב-GitHub: **Settings ← General ← Default branch**. מגדירים את `main` כענף ברירת המחדל.
2. ב-GitHub: **Settings ← Pages ← Source: GitHub Actions**.
3. כל עדכון שנכנס לענף `main` מעלה את האתר אוטומטית. אפשר גם להפעיל ידנית: **Actions ← Deploy to GitHub Pages ← Run workflow**.
4. כתובת האתר: https://g47ben-lang.github.io/A-platform-somewhere-between-a-chat-and-a-forum./

### 6. כניסה ראשונה
נכנסים לאתר ונרשמים. **המשתמש הראשון הופך למנהל.** אחר כך שולחים את הקישור לחברי הקהילה, ומאשרים אותם בדף **⚙️ ניהול**. יש שם גם כפתור "אישור כולם".

## פיתוח מקומי

```bash
cp .env.example .env.local   # ממלאים את הערכים מ-Supabase
npm install
npm run dev
```

בדיקות הרשאות מול Postgres מקומי:
```bash
PGHOST=localhost PGUSER=postgres supabase/tests/run.sh
```

## עדכון מסד הנתונים
אחרי כל שינוי ב-`supabase/schema.sql`, מדביקים את כל הקובץ מחדש ב-Supabase SQL Editor ולוחצים Run. הסקריפט מעדכן את המבנה במקום ולא מוחק נתונים.
